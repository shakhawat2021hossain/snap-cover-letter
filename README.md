# AI Cover Letter Generator

A full-stack application that generates professional cover letters using AI based on job descriptions and resumes. Users can edit the generated letters and download them as PDFs.

## ✨ Features

- 📄 **AI-Powered Cover Letter Generation** (using OpenAI GPT/Anthropic Claude/Google Gemini)
- ✏️ **Edit generated cover letters** before finalizing
- 📥 **Download as PDF** with clean formatting
- 📋 **Copy to clipboard** with one click
- 🎨 **Modern UI** with responsive design
- 🔄 **Multiple templates** to choose from

## 🛠 Tech Stack

### Frontend
- React + TypeScript
- Tailwind CSS
- React Router
- react-hot-toast
- jsPDF (for PDF generation)

### Backend
- Node.js + Express
- REST API architecture
- LLM API integration (OpenAI/Anthropic/Google)
